# 單字練習控制列微調

## 結論

本次調整聚焦於單字練習頁面的控制列尺寸與標籤文字，避免閱讀模式與操作模式之間的控制項視覺尺寸不一致。

## 決策

- 搜尋 input 的高度調整為 `2rem`。
- 閱讀模式按鈕的寬度與高度需與「開始測驗」按鈕相同。
- 「只顯示註記」改名為「僅註記」。

## 驗收條件

- 搜尋 input 的可視高度為 `2rem`。
- 「閱讀模式」與「操作模式」兩種狀態的模式切換按鈕，都與「開始測驗」按鈕寬高一致。
- 操作區不再顯示「只顯示註記」文字。
- 操作區顯示「僅註記」，且文字長度維持在 4 個字以內。

## 範圍

- 僅調整單字練習頁面的控制列 UI 尺寸與標籤。
- 不改變搜尋、註記篩選、閱讀模式切換或測驗啟動的既有行為。
