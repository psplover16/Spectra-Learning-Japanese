# 單字練習子路由調整提案草稿

## 唯一輸入

- `_private/discuss.txt`

## 討論結論

本次變更聚焦在「單字練習」子路由的操作區、單字表表頭與閱讀/操作模式切換，並將單字表底部遮擋問題列為本次功能檢查點。

資料整理部分則依目前討論中的既有規則處理：重複合併只針對「同 `text` 且同 `kanji`」的詞條，合併後放到最簡單的 JLPT stage，順序為 `N5 -> N4 -> N3 -> N2 -> N1`。

## 建議變更名稱

`adjust-vocabulary-practice-reading-mode`

## 變更範圍

### 1. 操作區移除練習 checkbox

- 移除操作區原本的「練習」checkbox。
- 此步驟為本次優先處理項目。

### 2. 單字表表頭新增練習 checkbox

- 將 `.vocabulary-header-toggle` 的 `gap` 調整為 `0.4rem`。
- 在單字表表頭中，於「單字」checkbox 同一列的 `th` 內新增「練習」checkbox。
- 這個新增的「練習」checkbox 與操作區原本被移除的「練習」checkbox 不同，屬於單字表顯示控制。
- 「單字」checkbox 與「練習」checkbox 的間距為 `0.5rem`。
- 預設只有「單字」checkbox 勾選。

### 3. 單字列顯示規則

- 只要表頭「單字」checkbox 有勾選，單字列顯示原本單字假名。
- 只有表頭「練習」checkbox 勾選、且「單字」checkbox 沒有勾選時，單字列顯示假名的平假名/片假名互換結果。
- 表頭「單字」checkbox 與「練習」checkbox 都沒有勾選時，單字列不顯示單字。

範例：

- `あさ` 顯示為 `アサ`
- `あサ` 顯示為 `アさ`

## 操作區 checkbox 排列

- 將操作區的「全部字音」checkbox 與「漢字」checkbox 移到「只顯示註記」checkbox 左側。
- 順序固定為：
  1. 漢字
  2. 全部字音
  3. 只顯示註記
- 預設狀態：
  - 「漢字」預設勾選。
  - 「全部字音」預設勾選。

## 閱讀模式與操作模式

### 模式切換按鈕

- 原本操作區 input 旁邊放置「全部字音」與「漢字」checkbox 的位置，改為新增一個模式切換按鈕。
- 按鈕文字在「閱讀模式」與「操作模式」之間交替。
- 顯示「閱讀模式」時，按鈕背景為淺綠色。
- 顯示「操作模式」時，按鈕背景為鮮紅色。
- 子路由「單字練習」預設為操作模式，因此初始按鈕文字顯示「閱讀模式」。

### 操作模式

- 排版與目前狀態幾乎相同。
- 除了本次已列出的 checkbox 與模式按鈕調整外，其餘排版維持目前狀態。
- 從閱讀模式切回操作模式時，單字表由上往下變矮，最後回到目前專案的原本狀態。

### 閱讀模式

- 按下「閱讀模式」按鈕後，頁面進入閱讀模式，按鈕切換為「操作模式」。
- 單字表由下往上長高，浮起並覆蓋操作區。
- 單字表不能覆蓋 input 與「閱讀模式 / 操作模式」按鈕所在那一行。
- 單字表背景不可透明，需有底色。
- 單字表底色採用目前專案背景色。

### 層級限制

- 測驗相關畫面的 z-index 必須高於本次新增或調整的覆蓋層級。

## 單字表底部遮擋檢查點

- 目前單字表最下方的單字無法看到，會被遮蓋。
- 本問題列為本次功能與驗收的檢查點。
- 完成後，單字表最下方的單字必須可完整看到。

## 重複單字合併需求

- 目前討論中的既有規則是：「同 `text` 且同 `kanji`」才合併。
- 合併後放到最簡單 stage，順序為 `N5 -> N4 -> N3 -> N2 -> N1`。
- 本次需求指出，目前專案仍有「同 `text` 且同 `kanji`，但不同 `stage`」的單字。
- 本次需要依既有規則合併這類資料。
- 後續新增單字時，也應避免再次產生「同 `text` 且同 `kanji`，但不同 `stage`」的重複資料。

## 驗收標準

1. 操作區不再顯示原本的「練習」checkbox。
2. 單字表表頭的單字欄位中顯示「單字」與新的「練習」checkbox，兩者間距為 `0.5rem`。
3. `.vocabulary-header-toggle` 的 `gap` 為 `0.4rem`。
4. 表頭「單字」checkbox 勾選時，單字列顯示原本假名。
5. 只有表頭「練習」checkbox 勾選時，單字列顯示平假名/片假名互換後的假名。
6. 表頭「單字」與「練習」checkbox 都未勾選時，單字列不顯示單字。
7. 操作區 checkbox 順序為「漢字 / 全部字音 / 只顯示註記」。
8. 「漢字」與「全部字音」預設為勾選。
9. 單字練習子路由預設為操作模式，初始按鈕顯示「閱讀模式」且背景為淺綠色。
10. 按下「閱讀模式」後，單字表以由下往上長高的特效覆蓋操作區，但不覆蓋 input 與模式切換按鈕列。
11. 進入閱讀模式後，按鈕顯示「操作模式」且背景為鮮紅色。
12. 按下「操作模式」後，單字表以由上往下變矮的特效回到原本狀態。
13. 單字表覆蓋時背景不透明，並使用目前專案背景色。
14. 測驗相關畫面的 z-index 高於本次閱讀模式覆蓋效果。
15. 單字表最下方的單字可以完整看到，不再被遮蓋。
16. 同 `text` 且同 `kanji` 但不同 `stage` 的單字，會依既有規則合併到最簡單 stage。
17. 未來新增單字時，不會再次產生同 `text` 且同 `kanji` 但不同 `stage` 的重複資料。

## 後續提案注意事項

- `$spectra-propose` 階段應把「同 `text` 且同 `kanji` 的重複詞條合併到最簡單 stage」納入正式規格或任務。
- 正式提案需要避免把「只看 `text` 相同」誤寫成合併條件。
- 實作前應確認閱讀模式覆蓋效果與測驗畫面的 z-index 關係，避免測驗 UI 被遮住。
