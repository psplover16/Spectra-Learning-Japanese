# 單字練習頁面捲動收合提案草稿

## 結論

**決策**：在「子路由 - 單字練習」頁面內，保留切換路由 UI 與既有排版；只讓該頁面中 table 以外的操作區塊，依照單字 table 的捲動位置逐步收合或展開。

**理由**：使用者實際操作時，單字 table 是主要閱讀區域。當 table 往下捲動時，應把更多畫面空間讓給 table；當 table 往上回到前段內容時，操作區塊再恢復到預設高度，方便重新調整 input、button、checkbox 等設定。

**捕捉位置**：後續可整理成對應變更的 `proposal.md`、`design.md` 與 `tasks.md`。

## 需求整理

目前「單字練習」頁面下方 table 放置單字，table 本身有滾動條。現有預設樣式需要保留，頁面初始狀態仍使用目前的 UI 與排版。

新的互動需求是：

- 切換路由 UI 不變。
- 整體排版基準不變。
- 只改變單字練習頁面本身的內部高度分配。
- table 以外，包含 input、button、checkbox 的操作區塊，會隨 table 往下捲動而逐步變矮。
- 單字 table 會隨 table 往下捲動而逐步變高。
- table 的最高狀態，是把該頁面可用空間幾乎全部占滿。
- table 往上捲動時，操作區塊逐步變高，table 逐步變矮。
- 當 table 回到頂部或預設區段時，頁面恢復目前的預設樣式。

## 建議行為模型

將 table 的垂直捲動位置視為控制比例：

- 捲動位置接近頂部：操作區塊維持預設高度，table 維持預設高度。
- 捲動位置逐漸往下：操作區塊高度逐漸縮小，table 高度同步增加。
- 捲動位置達到指定門檻：操作區塊縮到最小狀態，table 擴張到最大狀態。
- 捲動位置往回接近頂部：上述變化反向進行，直到恢復預設值。

這個變化應該是連續、平滑的，而不是突然切換。

## 範圍

包含：

- 單字練習子路由內部的高度配置。
- table 捲動事件與頁面區塊高度的聯動。
- input、button、checkbox 等操作區塊的收合高度。
- table 最大高度與預設高度之間的動態切換。
- 回到頂部時恢復原本預設樣式。

不包含：

- 修改切換路由 UI。
- 修改其他子路由頁面。
- 修改單字 table 的資料內容或欄位設計。
- 修改既有預設樣式的視覺基準。

## 驗收標準

- 進入單字練習頁面時，畫面與目前預設樣式一致。
- table 往下捲動時，操作區塊會逐步變矮，不會突然消失。
- table 往下捲動時，單字 table 會逐步變高。
- table 達到最大狀態時，table 會占用該頁面大部分或全部可用高度。
- table 往上捲動時，操作區塊會逐步恢復高度。
- table 回到頂部時，操作區塊與 table 高度都回到預設狀態。
- 切換路由 UI 在整個過程中不移動、不縮放、不改變樣式。
- 其他頁面不受這項互動影響。

## 待後續確認

- 操作區塊最小高度應該是完全收起，還是保留一小段可見區域。 完全收起
- table 擴張到最大時，是否允許蓋住操作區塊，或只是在同一頁面內重新分配高度。 table 往下捲動時，操作區塊以高度收合方式逐步讓出空間，table 使用釋出的高度擴張；table 不應以浮層或覆蓋方式遮住操作區塊。最大狀態下，操作區塊可收合至最小高度或完全不可見。
- 收合與展開的速度是否直接對應 table 捲動距離，或使用固定門檻與動畫曲線。直接對應 table 捲動距離
- 手機版與桌面版是否使用相同的收合比例。此項功能，在螢幕寬度 768以下才會觸發。
